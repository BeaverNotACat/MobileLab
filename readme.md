## Приложение:
Листалка пород котов основанная на [The Cat API](https://thecatapi.com/)

**Умеет**:
- показывать стастистику по породам
- искать по названия
- хранит, локальный список избранных пород
- хранит историю просмотра
- имеет TODO лист на поглад котов с этапами: найти, погладить, поглажен

**Offline first**
После получания данны с сервера они хранятся локально пока не просрочатся по настраиваевому TTL преференсу
Фоновый обработчик вычищает из базы устаревшие записи
*Политика обновления*: Кроме логичного если запись есть и не просрочена покажи её, иначе обнови, было принято еще спорное правило, если запись просрочена, но у нас нет сети все равно показать хоть что то. Вдохновлено приложением тбанка
